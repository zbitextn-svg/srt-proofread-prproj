# 拆条与时间轴

字幕看着「不顺」，八成不是字写错了，是**切点切在字中间**，或者**两条之间留了几帧空隙**导致画面跳。

---

## 1. 一条 = 一个语意单元

不是「不超 14 字就留一条」，而是每个能独立成句的块单独一条。

9 个字的主谓结构也可以拆：

```
她也 ｜ 变得越来越好了
我相信 ｜ 你也会犹豫
```

不要拿字数当标准。字数只是上限提醒。

---

## 2. 优先拆在这些位置

| 位置 | 例 |
|---|---|
| 主谓之间 | `她会` ｜ `很怀念这段时间` |
| 动宾之间 | `依然能够保有` ｜ `她这个初心` |
| 引语 / 从句前 | `嘉宾也会说` ｜ `这么硬吗` |
| 状语之后 | `希望未来` ｜ `不管在哪儿` |
| 并列项之间 | `我们还是` ｜ `合作` ｜ `工作伙伴` |
| 重复结构之间 | `再坚持坚持` ｜ `再坚持坚持` |
| 填充词独立 | `我觉得` ｜ `在我们之间的` |
| 现场指令独立 | `撒手` ｜ `退` ｜ `好` |

反例：不要在「的」后面硬切、不要在数量词中间切（「三｜年」）、
不要在专有名词中间切（「张｜老师」）。

---

## 3. 切点必须在气口上

判据是能量，不是听感：

- 切点处的能量应比局部语音中位数低 6dB 以上
- 全片切点的能量中位数应低 15dB 左右
- 切在语音峰值上的一定要挪

```bash
python3 audioalign.py 视频.mp4 字幕.srt --report 报告.md --split-suggest
```

报告里「切点能量」列是相对局部语音中位数的 dB 值。
`-58dB` 说明在静音里，`+0.1dB` 说明还贴着语音。长期停在 0 附近
的切点要复查。

`--split-suggest` 会列出条内的长静音位置（≥180ms），作为拆条参考点。
一条 6 秒的字幕如果中间有明显气口，基本都该拆。

---

## 4. 连上：间隔 ≤5 帧直接连

**这是硬规则。**

相邻字幕间隔 1–200ms 时，字幕会短暂消失再出现，画面看起来在跳。
把前一条的尾接到后一条的头。

```bash
python3 audioalign.py ... --join 0.2
# 或
python3 srt2pr.py ... --join 0.2
```

实现细节（踩过坑）：

- 用**毫秒整数**比较。浮点 `0.2` 可能是 `0.2000000000001`，
  正好 200ms 的间隔会被漏掉
- 连上是把前一条的 `end` 改成后一条的 `start`，不改后一条
- 25fps 下 5 帧 = 200ms；30fps 下 5 帧 = 166.7ms。
  `--join` 的参数是秒，换算时按帧率取
- **换人的地方不要连**。两个人交接时该留白，连上会让观众以为是同一人在说

---

## 5. 极短条是正常的

0.3s 的「撒手」「好」「对」是合法条目。

不要为了满足自己设的最短时长（比如 0.5s）去借前后时间——借来的时间
会把上一条的尾或下一条的头切掉，得不偿失。

**时长服从气口，不是气口服从时长。**

---

## 6. 换人必须拆条

同一个时间窗口里两个人说话，即使语义连得上，也要拆成两条。

- 判断依据：音色变化、说话人分离结果、画面口型
- 拆开后两条之间的间隔可以很小，但不要重叠
- 换人处的切点**不要做吸附**，保持原样（吸附可能会把边界挪进另一人的语音里）

`audioalign.py` 的吸附会给每条留 ±0.02s 的安全边界，避免制造重叠，
但它不知道谁在说话。如果素材里有说话人分离结果，换人处手动锁一下。

---

## 7. 吸附的安全边界

脚本的约束：

- 起点窗口：原起点 ±0.25s（`--max-shift` 可调）
- 终点窗口：原终点 ±0.25s
- 起点不早于上一条终点 + 20ms
- 终点不晚于下一条起点 − 20ms
- 吸附后按帧取整（`round(t*fps)/fps`）
- 终点取「第一个静音帧的前一帧」，贴着语音末尾

如果原时间码本身错得离谱（比如整体偏移 1 秒），吸附窗口覆盖不到，
这时候应该先做**整体偏移校正**：拿几条明显的句子算出平均偏移，
整轨平移后再吸附。

---

## 8. 长条复查清单

导出前扫一遍这些：

| 指标 | 阈值 | 处理 |
|---|---|---|
| 单条时长 | > 5s | 看有没有气口可以拆 |
| 语速 | > 9 字/秒 | 拆条或核对文本 |
| 语速 | < 2 字/秒 | 拖音，正常，但要确认没多留时间 |
| 字数 | > 16 | 基本都要拆 |
| 间隔 | 1–200ms | 连上 |
| 间隔 | < 0 | 重叠，必须修 |

`proofread.py` 和 `srtlib.stats()` 会给这些数。
