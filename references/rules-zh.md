# 唱词校对口径

从多轮实际返工里归纳出来的。**每一条背后都有踩过的坑**，不是想当然的规范。
先按这份做，再让用户逐条确认。

---

## 1. 语气词

### 删

句尾单独出现、只承担语气、去掉不影响意思的：

```
啊 呀 哇 哦 喔 噢 嗯 呃 唉 诶 哎 呗 嘿 哈
```

连用的整块删：

```
哎呀 哎哟 哎呀妈呀 我的妈呀 好家伙
```

### 留

```
吧 吗 嘛 呢
```

这三个承载疑问或软化语气，删了会改变语气甚至语义。

### 句中不动

「哎呀」在句首是感叹，可以删；夹在句子中间的，先看是不是实义感叹，
拿不准就留着并在清单里标出来让用户定。**逐条给依据，不要一刀切。**

### 特例

- 「哈喽」「hello」是招呼语，不是语气词，按英文规则处理（换中文「你好」）
- 句尾单字「哈」删；「哈哈」两字以上按笑声处理
- 语气词重复（「呀呀」「嗯嗯」）删到一个，但如果中间有停顿就是两次发声，拆两条

---

## 2. 笑声

整段删，连同前面的空格。

```
哈哈哈哈 → （删）
嘿嘿嘿   → （删）
呵呵     → （删）
```

**整条只有笑声/语气词的，整条删掉**，不要留一条空白字幕。

判断是不是笑声：连续两个以上相同拟声字 + 音频在该位置有明显的气声爆发。
如果只是一个人说了两次「哈」（中间有停顿），那是说话不是笑，按重复字处理。

---

## 3. 重复字

**这是最容易改错的地方。**

不一律当语音识别重影。判断标准只有一条：**中间有没有停顿**。

| 情况 | 处理 |
|---|---|
| 「我们就就坐着」中间没停顿 | 识别重影，删一个 →「我们就坐着」 |
| 「我们就」停顿 0.5s「就坐着」 | 真说了两遍，**保留两个「就」**，拆成两条 |
| 两个人先后说同一个词 | 保留，拆条，各自归各自 |
| 「那么」隔两秒又说「那么」 | 两个独立的话头，保留并拆条 |

工具只能提示，不能替你判断。`proofread.py` 的 `dup_char` 规则永远
`auto=False`，就是为了防止误删。

---

## 4. 英文

唱词里不留英文。用项目词表统一替换，**不要一个词一个说法**。

词表放在 `项目词表.json` 的 `en_map` 里，例如：

```json
{
  "en_map": {
    "OK": "好",
    "cue": "提",
    "social": "社交",
    "vlog": "视频日记",
    "PK": "对决"
  }
}
```

注意：

- 大小写不敏感（脚本用 `re.I`）
- 前后不能粘着字母（避免 `ok` 命中 `token`）
- 中英混排时英文两侧的空格要一起处理掉
- **别信扒词稿**。稿子里写英文，不代表字幕要写英文，按项目口径走

---

## 5. 数字

一律中文。

```
3年 → 三年        第2季 → 第二季
100 → 一百        2025 → 二零二五（年份逐位读）
```

百分比、小数、分数拿不准就标出来问，别自己编读法。
脚本只处理 0–9999 的整数，其余 `auto=False`。

---

## 6. 书名号与引号

| 对象 | 符号 | 例 |
|---|---|---|
| 作品名、节目名、歌名、影视名 | 《》 | 《作品甲》 |
| 组合名、外号、代号 | “” | “组合甲” |
| 引用别人的原话 | “” | 他说“再等等” |

**简称要还原成全称**再判断要不要加书名号。全称从项目词表里取，
不要在代码里写死。

同一部作品在全片必须写法一致。第一遍就统一，别改一半。

---

## 7. 人名

**一个字都不能错。**

- 只出现在花絮、边角里的名字，先问，不要按音猜
- 同音不同字（比如两个形近字）优先按公开资料核对
- 转录给的名字和你的判断不一致时，**保留转录并标注**，让用户定
- 姓氏 + 称谓（「X 哥」「X 姐」）里的姓同样要核

---

## 8. 的 / 地 / 得

逐条核，尤其：

- 动词后接补语用「得」：说**得**好、跑**得**快
- 状语修饰动词用「地」：认真**地**说、慢慢**地**走
- 定语用「的」：好**的**办法

口语里三者常混，字幕按书面语规范写。但**不要顺手改语感**——
用户说「就这样」，别改成「就这般」。

---

## 9. 行长与断句

- 一行 14 字是**参考线，不是硬线**
- 专有名词、书名号内容可以破例到 15–16 字
- 超长的按**语意**断，不按字数均分（见 `timeline.md`）
- 同一条内允许用**一个空格**分隔两个语意块，仅在时间上拆不开时用

```
真的 就这个名就卡住了
一个是这个 一个是那个
```

空格规则：

- 只用一个半角空格，不用两个
- 不在行首/行尾留空格
- 中英文之间不用空格（英文已经被换掉了）
- 全片空格用法要统一，别一会儿有一会儿没有

---

## 10. 标点

- 字幕结尾不留标点（句号、逗号都去掉）
- 问号、感叹号按需保留，但同一部片统一口径
- 省略号统一用「……」，不用「...」
- 引号内的话不加句号

---

## 11. 改动清单格式

每处改动一行，四列，缺一不可：

| # | 时间码 | 原文 | 改后 | 依据 |
|---|---|---|---|---|
| 12 | 0:47.32 | 我们要 cue 一下 | 我们要提一下 | 唱词不留英文，cue → 提 |

规矩：

- **原文必须逐字照抄**，不要「同上」「见上一条」
- 时间码用条目起点，精确到 10ms
- 依据写清是哪条规则，不要写「优化」「润色」
- 整条删除的，「改后」写「（整条删除）」并说明原因
- 拿不准的单独列一节「待确认」，不要混在已改清单里
